添加"运费"类别：
- 支付比例：100%

- 审批：平台审批 ✓，资金方审批 ✓

- 单笔限额：最小10，最大1000

## 常见问题排查

### 1. 支付申请看不到
- 检查用户权限，是否是平台用户
- 检查合同是否正确关联
- 检查浏览器 Network 是否有错误

### 2. 审批按钮不显示
- 检查申请状态是否正确
- 检查用户是否有审批权限

### 3. 支付执行失败
- 检查合同可用额度
- 检查后端日志

### 4. 利息计算不正确
- 检查年化利率配置
- 检查计息基数（360天）
- 检查利息开始时间
