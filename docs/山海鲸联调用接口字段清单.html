山海鲸联调用接口字段清单

文档说明

  • 文档目标：提供给山海鲸配置同学直接对接使用
  • 数据依据：基于当前项目已实现并已验证的 `dashboard` 聚合接口
  • 结论口径：结合当前真实数据状态、历史回算结果、接口真实返回、已确认排查结论整理

当前关键事实如下：

  1. `waybill_commission` 历史回算已执行成功，当前已恢复 `13023` 条平台收益记录。
  2. 新版 dashboard 主链路已恢复，核心总览、趋势、合作方榜单等接口不再为 `0`。
  3. 当前 `settled/accounted` 相关状态尚未沉淀，因此已结算、已入账、结算后几档多数仍为 `0`。
  4. `route_id / commission_contract_id` 仍未补齐，且相关主数据链路缺失，因此落地合作方与有效合同维度当前不可用。
  5. 无筛选直接拉全量趋势时，会出现 `1970-01-01` 首桶；山海鲸首版建议所有趋势图统一传 `startDate/endDate`。

统一响应结构如下：

{
  "code": 0,
  "message": "success",
  "data": {}
}

以下字段清单均以 `data` 内部字段为主。

1. /api/dashboard/overview

接口路径

`/api/dashboard/overview`

接口用途

用于经营总览 KPI 展示，输出运单规模、撮合业务总额、平台收益、待结算收益、已结算收益、日均收益以及维度覆盖情况。

查询参数列表

参数类型说明
`startDate``string`开始日期，建议 `YYYY-MM-DD`
`endDate``string`结束日期，建议 `YYYY-MM-DD`
`partnerName``string`合作方筛选，当前匹配 `revenue_records.financier_name`
`landingPartnerName``string`落地合作方筛选
`routeName``string`线路筛选

返回 JSON 示例

{
  "code": 0,
  "message": "success",
  "data": {
    "totalWaybillCount": 13023,
    "grossFreightAmount": 32177862.77,
    "platformIncome": 2604600,
    "pendingSettlementIncome": 2604600,
    "settledIncome": 0,
    "avgDailyIncome": 127.17,
    "effectiveContractCount": 0,
    "partnerCount": 1,
    "landingPartnerCount": 0
  }
}

字段清单表

字段路径类型含义当前是否可用当前是否可能为 0备注
`data.totalWaybillCount``number`命中 dashboard 事实口径的运单去重数可用是已通过历史回算恢复，当前真实值 `13023`，可直接做 KPI
`data.grossFreightAmount``number`撮合业务总额/撮合运费汇总可用是已恢复，当前真实值 `32177862.77`，优先取 `waybills.receivable_total`
`data.platformIncome``number`平台收益，即业务抽成金额求和可用是已恢复，当前真实值 `2604600`，可直接用于山海鲸展示
`data.pendingSettlementIncome``number`待结算收益，当前按 `status != accounted` 汇总可用是已恢复，当前真实值 `2604600`
`data.settledIncome``number`已结算/已入账收益当前不可用当前固定为 0当前 `waybill_commission` 记录没有 `accounted` 状态
`data.avgDailyIncome``number`平台收益 / 自然天数可用是代码 bug 已修复；当前有值，但无筛选时受 `1970-01-01` 历史脏日期影响，建议首版带日期范围
`data.effectiveContractCount``number`命中聚合条件的有效合同去重数当前不可用当前固定为 0`commission_contract_id` 未补齐，且 `contract_routes` 主数据为空
`data.partnerCount``number`命中聚合条件的合作方去重数可用是当前真实值 `1`，目前只命中 `金罗`
`data.landingPartnerCount``number`命中聚合条件的落地合作方去重数当前不可用当前固定为 0`route_id` 缺失，无法 join 到 `local_partners`

推荐用于山海鲸首版展示的字段

  • `data.totalWaybillCount`
  • `data.grossFreightAmount`
  • `data.platformIncome`
  • `data.pendingSettlementIncome`
  • `data.avgDailyIncome`
  • `data.partnerCount`

暂不建议用于山海鲸首版展示的字段

  • `data.settledIncome`：当前没有 `accounted`，固定为 `0`
  • `data.effectiveContractCount`：`commission_contract_id` 缺失，当前不可用
  • `data.landingPartnerCount`：`route_id / local_partners` 主数据链路缺失，当前不可用

12. /api/dashboard/business-scale-by-route

接口路径

`/api/dashboard/business-scale-by-route`

接口用途

按线路汇总撮合运费（grossFreightAmount），每行一条线路或一类无 route_id 的兜底分桶；口径与 overview / business-trend 的 grossFreightAmount 一致（waybills.receivable_total 优先，缺失回退 revenue_records.principal_amount）。

查询参数列表

参数类型说明
`startDate``string`开始日期，YYYY-MM-DD；过滤 revenue_date 下界（含）

`landingPartnerName``string`落地合作方筛选

总表

接口是否可用于山海鲸首版推荐程度原因
`/api/dashboard/overview`是高核心 KPI 已恢复，除 `settledIncome / effectiveContractCount / landingPartnerCount` 外，其他主字段可直接上屏
`/api/dashboard/income-trend`是高趋势值已恢复，适合首版趋势图；但务必带 `startDate/endDate`，避免全历史出现 `1970-01-01` 首桶
`/api/dashboard/business-trend`是高经营规模与收益趋势都可用；同样建议强制传日期范围
`/api/dashboard/partner-top`是高字段已恢复，可直接做榜单；当前只有 `金罗` 1 项，信息密度略低但可展示
`/api/dashboard/landing-partner-top`否低只有 fallback bucket `未命名落地合作方`，不是真实业务维度
`/api/dashboard/income-structure`否低当前只有“待结算收益”有值，“已结算收益”固定 `0`，结构图信息量不足
`/api/dashboard/settlement-progress`否低当前仅第一档有值，后四档固定 `0`，完整流程图不建议首版上屏
`/api/dashboard/partner-efficiency`是中字段可用，但当前只有 1 个合作方散点，更适合作为备选模块
`/api/dashboard/platform-revenue/overview`否低旧口径且忽略日期，不建议与统一 dashboard 混用
`/api/dashboard/waybills/overview`否低旧口径运单概览，不建议与 dashboard 统一口径同屏混用
`/api/dashboard/business-scale-by-route`是中线路维度撮合运费；默认 2026-03-01～今天；与 KPI grossFreightAmount 口径一致

山海鲸首版配置建议

建议优先上屏的模块

  1. 经营总览
  2. 收益趋势
  3. 经营趋势
  4. 合作方贡献 TOP
  5. 合作方效率分析
  6. 线路撮合运费排行：数据源 /api/dashboard/business-scale-by-route（可不传日期，默认自 2026-03-01 累计至今天）

建议先隐藏或延后的模块

  1. 落地合作方贡献 TOP
  • 原因：当前只有 fallback bucket `未命名落地合作方`
  1. 收益构成图
  • 原因：当前只有待结算收益有值，结构图信息量不足
  1. 结算进度完整流程图
  • 原因：当前仅第一档有值，后续阶段尚无真实状态沉淀

接入注意事项

  1. 趋势类接口首版统一传 `startDate`、`endDate`
  2. 不要将旧接口字段与新 dashboard 字段混用
  3. `partnerName` 当前实际映射 `revenue_records.financier_name`，属于现阶段聚合展示字段
  4. `landingPartner`、`effectiveContractCount` 当前不要作为首版核心指标绑定
  5. 线路榜使用 /api/dashboard/business-scale-by-route：grossFreightAmount 勿与旧接口 totalReceivable 混读
