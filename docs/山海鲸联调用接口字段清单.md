# 山海鲸联调用接口字段清单

## 文档说明

- 文档目标：提供给山海鲸配置同学直接对接使用
- 数据依据：基于当前项目已实现并已验证的 `dashboard` 聚合接口
- 结论口径：结合当前真实数据状态、历史回算结果、接口真实返回、已确认排查结论整理

当前关键事实如下：

1. `waybill_commission` 历史回算已执行成功，当前已恢复 `13023` 条平台收益记录。
2. 新版 dashboard 主链路已恢复，核心总览、趋势、合作方榜单等接口不再为 `0`。
3. 当前 `settled/accounted` 相关状态尚未沉淀，因此已结算、已入账、结算后几档多数仍为 `0`。
4. `route_id / commission_contract_id` 仍未补齐，且相关主数据链路缺失，因此落地合作方与有效合同维度当前不可用。
5. 无筛选直接拉全量趋势时，会出现 `1970-01-01` 首桶；山海鲸首版建议所有趋势图统一传 `startDate/endDate`。

统一响应结构如下：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

以下字段清单均以 `data` 内部字段为主。

## 1. /api/dashboard/overview

### 接口路径

`/api/dashboard/overview`

### 接口用途

用于经营总览 KPI 展示，输出运单规模、撮合业务总额、平台收益、待结算收益、已结算收益、日均收益以及维度覆盖情况。

### 查询参数列表

| 参数 | 类型 | 说明 |
|---|---|---|
| `startDate` | `string` | 开始日期，建议 `YYYY-MM-DD` |
| `endDate` | `string` | 结束日期，建议 `YYYY-MM-DD` |
| `partnerName` | `string` | 合作方筛选，当前匹配 `revenue_records.financier_name` |
| `landingPartnerName` | `string` | 落地合作方筛选 |
| `routeName` | `string` | 线路筛选 |

### 返回 JSON 示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "totalWaybillCount": 13023,
    "grossFreightAmount": 32177862.77,
    "platformIncome": 2604600,
    "pendingSettlementIncome": 2604600,
    "settledIncome": 0,
    "avgDailyIncome": 127.17,
    "effectiveContractCount": 0,
    "partnerCount": 1,
    "landingPartnerCount": 0
  }
}
```

### 字段清单表

| 字段路径 | 类型 | 含义 | 当前是否可用 | 当前是否可能为 0 | 备注 |
|---|---|---|---|---|---|
| `data.totalWaybillCount` | `number` | 命中 dashboard 事实口径的运单去重数 | 可用 | 是 | 已通过历史回算恢复，当前真实值 `13023`，可直接做 KPI |
| `data.grossFreightAmount` | `number` | 撮合业务总额/撮合运费汇总 | 可用 | 是 | 已恢复，当前真实值 `32177862.77`，优先取 `waybills.receivable_total` |
| `data.platformIncome` | `number` | 平台收益，即业务抽成金额求和 | 可用 | 是 | 已恢复，当前真实值 `2604600`，可直接用于山海鲸展示 |
| `data.pendingSettlementIncome` | `number` | 待结算收益，当前按 `status != accounted` 汇总 | 可用 | 是 | 已恢复，当前真实值 `2604600` |
| `data.settledIncome` | `number` | 已结算/已入账收益 | 当前不可用 | 当前固定为 0 | 当前 `waybill_commission` 记录没有 `accounted` 状态 |
| `data.avgDailyIncome` | `number` | 平台收益 / 自然天数 | 可用 | 是 | 代码 bug 已修复；当前有值，但无筛选时受 `1970-01-01` 历史脏日期影响，建议首版带日期范围 |
| `data.effectiveContractCount` | `number` | 命中聚合条件的有效合同去重数 | 当前不可用 | 当前固定为 0 | `commission_contract_id` 未补齐，且 `contract_routes` 主数据为空 |
| `data.partnerCount` | `number` | 命中聚合条件的合作方去重数 | 可用 | 是 | 当前真实值 `1`，目前只命中 `金罗` |
| `data.landingPartnerCount` | `number` | 命中聚合条件的落地合作方去重数 | 当前不可用 | 当前固定为 0 | `route_id` 缺失，无法 join 到 `local_partners` |

### 推荐用于山海鲸首版展示的字段

- `data.totalWaybillCount`
- `data.grossFreightAmount`
- `data.platformIncome`
- `data.pendingSettlementIncome`
- `data.avgDailyIncome`
- `data.partnerCount`

### 暂不建议用于山海鲸首版展示的字段

- `data.settledIncome`：当前没有 `accounted`，固定为 `0`
- `data.effectiveContractCount`：`commission_contract_id` 缺失，当前不可用
- `data.landingPartnerCount`：`route_id / local_partners` 主数据链路缺失，当前不可用

### 字段清单表

| 字段路径 | 类型 | 含义 | 当前是否可用 | 当前是否可能为 0 | 备注 |

| `data.granularity` | `string` | 聚合粒度 | 可用 | 否 | 默认 `day`，可切换 `week/month` |

| `data.items[].pendingSettlementIncome` | `number` | 该时间桶待结算收益 | 可用 | 是 | 已恢复，当前与 `platformIncome` 基本一致 |
| `data.items[].settledIncome` | `number` | 该时间桶已结算收益 | 当前不可用 | 当前固定为 0 | 当前没有 `accounted` 数据 |

### 推荐用于山海鲸首版展示的字段

- `data.items[].date`
- `data.items[].platformIncome`
- `data.items[].pendingSettlementIncome`

说明：首版请强制带 `startDate/endDate`，不要直接拉全历史。

### 暂不建议用于山海鲸首版展示的字段

- `data.items[].settledIncome`：当前固定为 `0`
- 不带日期范围的全量趋势：会出现 `1970-01-01` 首桶，影响图表观感与均值理解

## 11. /api/dashboard/region-summary

### 接口路径

`/api/dashboard/region-summary`

### 接口用途

- 供 **山海鲸中间中国地图主视觉** 使用，展示 **近 7 天（默认）** 区域业务分布（运单数、平台收益、落地合作方数）。
- **默认不传日期** 时即 **近 7 天（含今天）**；`data.startDate` / `data.endDate` 回显实际统计窗口，无需调用方推算。
- **`regionName`**：城市级 **展示名称**（tooltip、标签）。**`provinceName`**： **省级定位/映射**（省界、按省着色等）。

### 查询参数列表

| 参数 | 类型 | 说明 |
|---|---|---|
| `startDate` | `string` | 开始日期 `YYYY-MM-DD`；与 `endDate` 均不传时，服务端默认近 7 天 |
| `endDate` | `string` | 结束日期 `YYYY-MM-DD` |
| `partnerName` | `string` | 合作方筛选，匹配 `revenue_records.financier_name` |
| `landingPartnerName` | `string` | 落地合作方筛选 |
| `routeName` | `string` | 线路筛选 |

### 默认时间范围

- 未传 `startDate` 且未传 `endDate`：`endDate` = 服务器本地 **今天**，`startDate` = **今天往前 6 天**，闭区间共 **7** 个自然日；`data.dateScope` = `"last7days"`。
- 传了任一端日期：`data.dateScope` = `"custom"`，`data.startDate` / `data.endDate` 与本次查询条件一致。

### 区域映射与过滤（摘要）

- 原始区域：主数据 **`areas.name`**（经 `local_partners` → `routes` 与收益事实关联）。
- **`XX融满`** → 去掉「融满」得城市名；**合作方 `金罗` 且无区域** → **成都 / 四川**；城市→省份见只读 dashboard 文档第 11 节静态表。
- **输出过滤**：`regionName = 未维护区域`、`provinceName = 未知` 的桶 **不在 `items` 中返回**，地图首版直接渲染返回列表即可。

### 返回 JSON 示例（默认近 7 天）

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "dateScope": "last7days",
    "startDate": "2026-04-03",
    "endDate": "2026-04-09",
    "items": [
      {
        "regionName": "成都",
        "provinceName": "四川",
        "waybillCount": 1233,
        "platformIncome": 95781.15,
        "landingPartnerCount": 1,
        "routeCount": 12,
        "activeRouteCount": 12,
        "displayText": "四川｜平台收益，95781.15 元｜活跃线路，12 条"
      }
    ]
  }
}
```

### 返回 JSON 示例（自定义范围）

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "dateScope": "custom",
    "startDate": "2026-04-01",
    "endDate": "2026-04-07",
    "items": []
  }
}
```

### 字段清单表

| 字段路径 | 类型 | 含义 | 当前是否可用 | 当前是否可能为 0 | 备注 |
|---|---|---|---|---|---|
| `data.dateScope` | `string` | `last7days` / `custom` | 可用 | 否 | 与是否传参一致 |
| `data.startDate` | `string` | 统计窗口下界（含） | 可用 | 否 | 默认近 7 天时自动填充 |
| `data.endDate` | `string` | 统计窗口上界（含） | 可用 | 否 | 同上 |
| `data.items[].regionName` | `string` | 城市展示名 | 可用 | 视数据 | 已过滤「未维护区域」 |
| `data.items[].provinceName` | `string` | 省级定位用 | 可用 | 视数据 | 已过滤「未知」 |
| `data.items[].waybillCount` | `number` | 区域运单去重数 | 可用 | 是 | 与 dashboard `waybillCount` 口径一致 |
| `data.items[].platformIncome` | `number` | 区域平台收益 | 可用 | 是 | 业务抽成求和 |
| `data.items[].landingPartnerCount` | `number` | 落地合作方去重数 | 可用 | 是 | 无落地关联时可为 0 |

| `data.items[].displayText` | `string` | 省份+收益+活跃线路拼装文案 | 可用 | 否 | 直接绑大字/副标题 |

### 推荐用于山海鲸首版展示的字段

- **整接口推荐用于中间中国地图主视觉**：`data.items[]` 全量字段，配合 `data.startDate` / `data.endDate` / `data.dateScope` 做标题或筛选说明
- `data.items[].regionName`、`data.items[].provinceName`、`data.items[].waybillCount`、`data.items[].platformIncome`、`data.items[].landingPartnerCount`、`data.items[].routeCount`、`data.items[].activeRouteCount`、`data.items[].displayText`

### 暂不建议用于山海鲸首版展示的字段

- 暂无；本接口即为地图专用，不传日期时默认近 7 天即可满足首版「区域态势」刷新需求

## 山海鲸首版配置建议

### 建议优先上屏的模块

1. 经营总览
2. 收益趋势
3. 经营趋势
4. 合作方贡献 TOP
5. 合作方效率分析
6. **中间中国地图（区域业务分布）**：数据源 `/api/dashboard/region-summary`，默认近 7 天，定时刷新即可

### 建议先隐藏或延后的模块

1. 落地合作方贡献 TOP
   - 原因：当前只有 fallback bucket `未命名落地合作方`
2. 收益构成图
   - 原因：当前只有待结算收益有值，结构图信息量不足
3. 结算进度完整流程图
   - 原因：当前仅第一档有值，后续阶段尚无真实状态沉淀

### 接入注意事项

1. 趋势类接口首版统一传 `startDate`、`endDate`
2. 不要将旧接口字段与新 dashboard 字段混用

4. `landingPartner`、`effectiveContractCount` 当前不要作为首版核心指标绑定
5. 中间中国地图使用 `/api/dashboard/region-summary`：可不传日期（默认近 7 天）；以 `data.startDate`/`endDate` 展示窗口；地图绑定 `provinceName`，文案用 `regionName`
