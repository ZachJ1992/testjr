## 1. 系统概述

### 1.1 系统定位

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           登途云金融平台                                 │
│                                                                         │
│   为物流行业提供供应链金融服务，连接资金方、物流企业（融资方）、平台      │
│                                                                         │
│   核心能力：                                                            │
│   • 多种融资合作模式（三方融资、撮合业务、抽成、定向支付）              │
│   • 运单数据管理与费用结算                                              │
│   • 多租户数据隔离与权限控制                                            │
│   • 自动化账单生成与对账                                                │
└─────────────────────────────────────────────────────────────────────────┘
```

## 4. 合同类型与业务流程

### 4.1 合同类型概览

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           合同类型矩阵                                   │
├─────────────────┬─────────────┬─────────────┬─────────────┬─────────────┤
│     合同类型    │    参与方   │   资金流向  │   收益模式  │   结算方式  │
├─────────────────┼─────────────┼─────────────┼─────────────┼─────────────┤
│  三方融资合同   │ 资金方      │ 资金方 →    │  利息收入   │  按期还款   │
│  (financing)    │ 融资方      │ 融资方      │  (年化利率) │             │
│                 │ 平台        │             │             │             │
├─────────────────┼─────────────┼─────────────┼─────────────┼─────────────┤
│  撮合业务合同   │ 融资方      │ 运费中抽取  │  运费分成   │  周期结算   │
│  (brokerage)    │ 平台        │ → 平台      │  (百分比)   │             │
├─────────────────┼─────────────┼─────────────┼─────────────┼─────────────┤
│  抽成合同       │ 融资方      │ 指定费用    │  费用抽成   │  周期结算   │
│  (commission)   │ 平台        │ → 平台      │  (百分比/   │             │
│                 │             │             │   固定金额) │             │
├─────────────────┼─────────────┼─────────────┼─────────────┼─────────────┤
│  定向支付合同   │ 资金方      │ 资金方 →    │  利息+     │  按期还款   │
│  (directed_pay) │ 融资方      │ 运单费用    │  服务费     │             │
│                 │ 平台        │ (司机等)    │             │             │
└─────────────────┴─────────────┴─────────────┴─────────────┴─────────────┘
```

### 4.2 三方融资合同流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        三方融资合同业务流程                              │
└─────────────────────────────────────────────────────────────────────────┘

1. 合同建立阶段
   ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
   │ 平台创建 │ → │ 选择    │ → │ 配置    │ → │ 合同    │
   │ 合同    │    │ 资金方  │    │ 额度/   │    │ 生效    │
   │         │    │ 融资方  │    │ 利率等  │    │         │
   └─────────┘    └─────────┘    └─────────┘    └─────────┘

2. 融资使用阶段
   ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
   │ 融资方  │ → │ 平台    │ → │ 资金方  │ → │ 额度    │
   │ 申请    │    │ 审批    │    │ 放款    │    │ 使用    │
   │ 用款    │    │         │    │         │    │         │
   └─────────┘    └─────────┘    └─────────┘    └─────────┘

3. 利息计算与还款
   ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
   │ 每日    │ → │ 生成    │ → │ 融资方  │ → │ 额度    │
   │ 计息    │    │ 账单    │    │ 还款    │    │ 释放    │
   └─────────┘    └─────────┘    └─────────┘    └─────────┘

利息计算公式:
┌─────────────────────────────────────────────────────────────────────────┐
│  日利息 = 使用金额 × 年化利率 ÷ 360                                     │
│  应还金额 = 本金 + 累计利息                                             │
└─────────────────────────────────────────────────────────────────────────┘
```

### 4.3 撮合业务合同流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        撮合业务合同业务流程                              │
└─────────────────────────────────────────────────────────────────────────┘

1. 合同配置
   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
   │ 创建合同    │ → │ 配置抽成    │ → │ 合同生效    │
   │ 绑定融资方  │    │ • 运费 5%   │    │             │
   │             │    │ • 利润 10%  │    │             │
   └─────────────┘    └─────────────┘    └─────────────┘

2. 运单关联与计算
   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
   │ 运单数据    │ → │ 自动关联    │ → │ 计算分成    │
   │ 进入系统    │    │ 合同        │    │ 金额        │
   └─────────────┘    └─────────────┘    └─────────────┘
           │
           ▼
   ┌─────────────────────────────────────────────────────────────────┐
   │  运单A: 运费 10,000 → 抽成 500 (5%)                             │
   │  运单B: 运费  8,000 → 抽成 400 (5%)                             │
   │  运单C: 利润  2,000 → 抽成 200 (10%)                            │
   └─────────────────────────────────────────────────────────────────┘

3. 结算周期
   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
   │ 到达结算日  │ → │ 汇总本期    │ → │ 生成账单    │
   │ (如每月20) │    │ 抽成金额    │    │ 平台收款    │
   └─────────────┘    └─────────────┘    └─────────────┘
```

### 6.2 账单生成流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        账单生成流程                                      │
└─────────────────────────────────────────────────────────────────────────┘

1. 定时检查 (每日执行)
   ┌───────────────┐
   │ 检查所有合同  │
   │ 是否到结算日  │
   └───────┬───────┘
           │
           ▼
   ┌───────────────────────────────────────────────────────────────┐
   │  遍历合同:                                                     │
   │  for each contract:                                           │
   │    if today == contract.settlementDay:                        │
   │      generateSettlement(contract)                             │
   └───────────────────────────────────────────────────────────────┘

2. 账单生成 (以定向支付为例)
   ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
   │ 查询本期      │ → │ 计算每笔     │ → │ 汇总生成     │
   │ 支付记录      │   │ 利息         │   │ 结算单       │
   └───────────────┘   └───────────────┘   └───────────────┘

3. 利息计算
   ┌─────────────────────────────────────────────────────────────────┐
   │  for each payment in period:                                    │
   │    days = (结算日 - 支付日期)                                   │
   │    interest = payment.amount × annualRate / 360 × days          │
   │    totalInterest += interest                                    │
   └─────────────────────────────────────────────────────────────────┘

4. 结算单内容
   ┌─────────────────────────────────────────────────────────────────┐
   │  结算单号: SET20260115001                                       │
   │  合同编号: DPC20260101XXX                                       │
   │  结算周期: 2026-01-01 ~ 2026-01-15                              │
   │  ─────────────────────────────────────────────                  │
   │  本金总额: 100,000.00                                           │
   │  利息总额:   1,250.00 (年化9%, 50天)                            │
   │  服务费用:     500.00                                           │
   │  ─────────────────────────────────────────────                  │
   │  应还总额: 101,750.00                                           │
   │  应还日期: 2026-01-20 (含5天宽限期)                             │
   └─────────────────────────────────────────────────────────────────┘
```
